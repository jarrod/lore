# Support

Use [GitHub Discussions](https://github.com/jarrod/lore/discussions) for installation help, usage questions, and open-ended design conversation.

Use [GitHub Issues](https://github.com/jarrod/lore/issues) for reproducible bugs and scoped feature requests. Include the Lore version, operating system, command, compact JSON output, and a minimal portable bundle when possible. Remove sensitive knowledge before sharing a bundle.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
