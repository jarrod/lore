# Security Policy

## Supported versions

Security fixes are provided for the latest published Lore release. Users should reproduce an issue with the latest version before reporting it when safe to do so.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's [private vulnerability reporting](https://github.com/jarrod/lore/security/advisories/new) to send the maintainers a confidential report.

Include the affected version and platform, impact, reproduction steps or proof of concept, and any suggested mitigation. Avoid accessing data that is not yours and stop testing once the issue is demonstrated.

The maintainers will acknowledge the report as soon as practical, assess severity and affected versions, coordinate a fix and disclosure with the reporter, and credit the reporter unless anonymity is requested.
